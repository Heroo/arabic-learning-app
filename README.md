# Arabic Learning App — MVP

Prosty MVP uczący liter arabskich. Funkcje:
- Lista liter z przykładami.
- Odtwarzanie wymowy przez Web Speech API (darmowe, wbudowane w przeglądarkę).
- Aktywne podświetlanie litery w przykładach podczas odtwarzania.

Uruchomienie lokalne:

```bash
cd /workspaces/arabic-learning-app
npm install
npm run dev
```

Ograniczenia i dalsze kroki:
- Web Speech API zależy od przeglądarki (najlepiej Chrome/Edge/Firefox z obsługą TTS dla `ar`).
- Można podmienić na darmowe nagrania CC z Wikimedia Commons — dodam to na życzenie.
